Features

Everything you need on stage

Built for live performance: bands, speakers, preachers, actors — anything spoken or sung in front of an audience.

🎤

Multi-singer colors

Each performer gets their own color. Sections and individual lines are color-coded so everyone instantly finds their part.

🎸

Aligned chords

Chords appear above lyrics with pixel-perfect alignment, guaranteed by the bundled PT Mono monospace font.

📺

Multi-screen

Prompter mode automatically goes full-screen on the external display — projector, stage TV, or any secondary output.

🦶

Bluetooth foot pedal

Any Bluetooth HID pedal is supported. Manual mode (scroll, next/previous song) or auto-scroll mode (start, pause, change song with a single press). See compatible pedals →

📱

iPad sync

Built-in server accessible on the local Wi-Fi network. Open http://prompt-live.local:8765 in Safari — lyrics, scroll and auto-scroll synced in real time.

✏️

Built-in editor

WYSIWYG editor with live preview. Edit from any external editor — the prompter reloads automatically on save.

⚡

Smooth scrolling

Fluid animation with 5 speed levels for both pedal and keyboard. ↑↓ to scroll, ←→ for previous/next song.

📂

Auto setlist

Load a folder of numbered .prompt files — the running order is set automatically.

🕐

Stage clock

Clock displayed in the control window to keep an eye on show timing without leaving the interface.

.prompt format

Simple syntax, precise result

Plain text files readable by any editor. A lightweight syntax to define lyrics, chords, sections and colors.

Titre: Amazing Grace TailleParoles: 32 TailleAccords: 18 CouleurSection: jaune CouleurAccords: gris @Alice: Rouge @Bob: Bleu @Clara: Violet [Intro] (Acoustic guitar — capo 2) G Cmaj7/E Amazing grace, how sweet the sound [Verse 1]@Alice D G That saved a wretch like me @Bob G D I once was lost, but now am found
  • ⚙️
    Configuration header
    Title, font sizes, colors — everything is per-song.
  • 🏷️
    Singer tags @Name
    Define a color per singer in the header, then annotate each line or section.
  • 🎵
    Automatic chord detection
    Any line whose tokens match [A-G][#b]?... is rendered as a chord line.
  • 📝
    Notes and stage directions
    Lines in parentheses are displayed in italic grey — instructions for the musicians.
  • 🔢
    Automatic setlist order
    Prefix files with a number: 01_..., 02_...
  • 🎨
    10 named colors + hex
    rouge, bleu, vert, orange, jaune, violet, cyan, rose, blanc, gris — or any #RRGGBB code.

macOS security

The app is not Apple-notarized. If macOS blocks the launch, open a Terminal and run:
xattr -dr com.apple.quarantine /Applications/Prompt-Live.app
Then relaunch normally. Only needed once.

Windows security

Windows SmartScreen may show a warning on first launch. Click More info then Run anyway. Only needed once.

Run from source

git clone https://github.com/jfpucheu/prompt-live.git
cd prompt-live && python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt && ./run.sh
