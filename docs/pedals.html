⌨️ Touches reconnues par Prompt-Live

Prompt-Live écoute ces touches en intercepteur global — le prompteur n'a pas besoin d'être au premier plan.

Mode manuel

Touches Action
↓ Espace F5 ↓ Défilement vers le bas
↑ F6 ↑ Défilement vers le haut
↓ ×2 en bas de page → Chanson suivante
↑ ×2 en haut de page ← Chanson précédente (positionnée en bas)

Mode défilement automatique

Activer la checkbox Défilement auto dans la fenêtre de contrôle. La pédale pilote alors le défilement automatique :

Action Résultat
N'importe quelle pédale — défilement arrêté ▶ Démarre le défilement auto
N'importe quelle pédale — défilement en cours ⏸ Met en pause
N'importe quelle pédale — en bas de page → Chanson suivante (défilement stoppé)
N'importe quelle pédale — nouvelle chanson ▶ Redémarre le défilement

Si ton pédalier envoie d'autres touches (ex. Page Bas, F1…), il suffit d'ajouter la touche dans _PEDAL_DOWN_KEYS / _PEDAL_UP_KEYS dans main.py. Le label Touche reçue dans la fenêtre de contrôle indique en temps réel quelle touche est envoyée par la pédale.
